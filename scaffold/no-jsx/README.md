# White Label generated site

This project was generated with the **plain TypeScript** template option.

- Pages and views are `.ts` files.
- Templates return HTML strings instead of using JSX/TSX syntax.
- React is not required.
- White Label Model, View, Router, and Mediator are used the same way as in the JSX template.

## Commands

```sh
npm install
npm run build
npm test
npm run audit
```

If you prefer JSX syntax for templates, generate a new project with `--jsx` or answer **Yes** to the generator's JSX question.
